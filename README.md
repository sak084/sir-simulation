# sir_simulation

An epidemic model simulation for COVID-19 transmission with vaccination using Python and matplotlib. 
Models the SVEIR framework (Susceptible, Vaccinated, Exposed, Infectious, Recovered) using Delta variant parameter estimates from a small US city in the 2021 vaccine rollout.

Ideas for future implementation:
- fit model to analyze real-world data
- herd immunity threshold analysis with factors like vaccine efficacy
- build a visualization with sliders for the variables
